# LuvByTen E-Commerce Platform

## Project Description

LuvByTen E-Commerce Platform is a single-seller online shopping website developed for a business specializing in ready-to-wear (RTW) clothing and baby essentials. This project aims to combine e-commerce functionality with digital marketing strategies to study how online marketing influences customer purchase decisions.

The platform allows customers to browse products, add items to cart, place orders, and interact with digital marketing features such as promotions and product reviews.

---

## Objectives

This project aims to:

- Identify digital marketing tools that influence customer buying decisions
- Evaluate the usability of the e-commerce platform
- Analyze how product presentation, promotions, and customer reviews affect trust
- Improve customer engagement through integrated digital marketing
- Provide insights for SMEs in adopting online business strategies

---

## Features

- User Registration and Login
- Product Catalog
- Add to Cart
- Shopping Cart
- Checkout System
- Order Management
- Admin Dashboard
- Sales Reports
